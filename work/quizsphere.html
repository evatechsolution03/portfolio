Case Study

Real-Time Quiz Platform

QuizSphere

Developed from a real organisation requirement for a more organised and interactive way to conduct quiz competitions.

Private Project
QuizSphereHost control · live scoring · mobile join

01 — Overview

QuizSphere is a real-time live quiz platform developed from an organisation's requirement for a more organised and interactive way to conduct quiz competitions.

02 — The Requirement

The organiser needed a dedicated way to run quiz events without relying on ad-hoc tools for every round.

03 — The Challenge

Traditional quiz events can require manual question management, answer collection, scoring and leaderboard handling, especially when multiple teams participate.

04 — The Solution

QuizSphere provides a Windows-based host application where the organiser can manage questions, create games and control the live quiz while participants join from their phones through a QR code over the same local Wi-Fi network.

05 — Key Features

  • Individual mode and group / team mode
  • QR-based joining and browser-based participant access
  • Real-time answers, configurable timer and automatic scoring
  • Randomized questions with no repeats during a question cycle
  • Live leaderboard and team answer locking
  • Game history and question bank management
  • SQLite local database, local HTTP server and WebSocket communication
  • No cloud dependency for the core game

06 — Technology

  • Flutter
  • Dart
  • SQLite
  • WebSockets
  • Local HTTP server
  • Browser-based web UI

Host: Windows desktop application. Participants: mobile browser.
