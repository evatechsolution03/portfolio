Case Study

Yoga & Wellness Studio Management

Aurenix

A mobile application developed by Evatech Solutions to bring everyday studio operations into one place.

Private Project

01 — Overview

Aurenix is a yoga and wellness studio management mobile application designed to bring everyday studio operations into one product.

02 — The Requirement

Studio teams needed a practical way to manage members, classes, attendance and payments in one place from a mobile application.

03 — The Challenge

Studio operations often spread across separate tools for scheduling, messaging, payments and student records, which makes day-to-day work harder to follow.

04 — The Solution

Aurenix is a mobile application for studio operations so memberships, classes, attendance, payments and communication can be managed from one product.

05 — Key Features

  • Member, student and membership management
  • Class scheduling and attendance tracking
  • Payment management and revenue tracking
  • Broadcast messages and notifications
  • Expense tracking and studio dashboard
  • Quick actions, plans and analytics views

06 — Technology

  • Flutter
  • Dart
  • Firebase
  • Cloud Firestore

Platform: mobile application.
